## Lecture Notes & Concept Summary

### Day 01: Foundations of Programming
* **Evolution of Data Representation:** Traced the historical shift from primitive tally tracking to positional number systems.
* **Number Systems:** Mastered cross-system conversions across Binary (Base-2), Decimal (Base-10), Octal (Base-8), and Hexadecimal (Base-16).
* **Hardware & Optimization:** Explored how complex data structures resolve down to binary bits and why architectural efficiency matters.

### Day 02: Flowcharts, Pseudocode & Algorithmic Logic
* **Problem-Solving Framework:** Broken down the standard pipeline—analyzing problem statements, identifying inputs, designing approaches, implementing, and debugging.
* **Flowchart Architecture:** Standardized visual mapping using symbols (Terminals, Inputs/Outputs, Processing blocks, Decision diamonds, and Flow directional arrows).
* **Control Structures & Loops:** 
  * Implemented conditional branching (`if-else` logic for salary evaluations, weather checks, and even/odd determinations using modulo operators).
  * Designed iterative execution loops (printing sequences up to $N$, calculating natural number sums, and testing primality logic).

### Day 03: Starting C++ & Writing Your First Program
* **Language Transition:** Bridging the gap from conceptual pseudocode to actual programming syntax using C++.
* **IO Operations:** Utilizing standard input and output streams (`std::cout` for printing outputs and `std::cin` for reading user values).
* **First Executable Code:** Structuring a basic C++ program, including header files, the `main()` function execution block, and clean formatting standards.
